# Eurocode 3 Engineer

نسخة أولية محلية ببايثون 3 للمساعدة في الفحوصات الأساسية للعناصر الفولاذية وفق
Eurocode 3. هذه الأداة ليست بديلاً عن التصميم والمراجعة من مهندس إنشائي معتمد.

## التشغيل

```bash
cd eurocode3_engineer
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

يمكن تشغيل الفحوصات دون واجهة:

```bash
python3 -m eurocode3.cli example.json
```

الوحدات في ملف الإدخال: mm, kN, kN·m, MPa.

## النسخة الأولية

تتضمن فحوصات الشد، الضغط مع الانبعاج حول المحورين، العزم، القص، وتفاعل
العزم مع القوة المحورية. يجب إدخال خصائص القطاع والأحمال يدويًا؛ الصور والملفات
المرفوعة تحفظ كمرجع ولا تُحوّل تلقائيًا إلى نموذج تصميم موثوق.
