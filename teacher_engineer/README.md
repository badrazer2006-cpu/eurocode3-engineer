# Eurocode 3 Teacher Engineer

برنامج محلي تعليمي ومساعد هندسي أولي لمنشآت الفولاذ وفق Eurocode 3.

## التشغيل على Windows

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run app.py
```

ثم افتح `http://localhost:8501`.

الصور تستخدم للملاحظة والشرح فقط. يجب إدخال الأبعاد والأحمال يدويًا ومراجعتها
من مهندس إنشائي معتمد قبل أي تنفيذ.
